# Despertador de la demo de NuevaMente

Cada 3 horas, GitHub Actions abre https://nuevamente-ia.streamlit.app en un navegador sin pantalla para que Streamlit Community Cloud no duerma la app. Si la encuentra dormida, pulsa el botón para despertarla.

- Correrlo a mano: pestaña **Actions** → **Despertar la demo** → **Run workflow**.
- Apagarlo: pestaña **Actions** → **Despertar la demo** → **⋯** → **Disable workflow**.
